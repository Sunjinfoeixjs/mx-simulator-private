## 四、复跑

```bash
cd 协议资料/网上资料_20261023
python build_data.py            # 生成 + 打印汇总
python build_data.py --check    # 只交叉校验，不写文件
```

脚本内部会做三向校验（招式名 ↔ magicdata、宠物技能 ↔ petskill.py、场景名 ↔ findpathdata.py），
缺口写 `gaps.json` 不阻断；解析条数异常（如精修 ≠ 120）才 `exit 1` 并写 `unresolved.json`。
