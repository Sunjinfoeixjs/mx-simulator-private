# 物品系统实现报告（模拟服）

> 日期：2026-10-16　文件：`tools/sim/m4_server.py`
> 依据：`src/netitem.py`（协议）+ `src/item.py`（容器/槽位）+ `src/data/itemdata.py`（造型表）
> 验证：协议级 7/7 + 真实客户端实测（悬停查看 + 使用生效）

## 1. 协议（逆向结论）

| 方向 | opcode | 常量 | 载荷 |
|---|---|---|---|
| S2C | 32 | `netitem.S2CItemKey` | `id(4) key(2)` |
| S2C | **33** | `netitem.S2CItemAdd` | `type(1) id(4) shape(4) special_flag(2) quantity(1) pos(1)` |
| S2C | 34 | `netitem.S2CItemDel` | `type(1) id(4)` |
| S2C | 35 | `netitem.S2CItemQuantity` | `id(4) quantity(1) flash(1)` |
| S2C | 36 | `netitem.S2CItemPos` | `type(1) id(4) pos(1)` |
| S2C | 37 | `netitem.S2CAskBind` | `id(4)`（客户端弹确认框 → 回 C2S 37） |
| S2C | 38 | `netitem.S2CItemString` | `id(4) infoext(变长 NUL 结尾)` |
| C2S | 32 | `C2SItemGet(id)` | `id(4)` |
| C2S | 33 | `C2SItemDrag(id, source, dest)` | `id(4) source(1) dest(1)` |
| C2S | 34 | `C2SItemUse(id)` | `id(4) 0(4)` |
| C2S | 35 | `C2SItemString(id, flag)` | `id(4) flag(1)` |
| C2S | 36/37/38 | `ItemFullUse / AnswerBind / ItemLock` | `id(4) [+1B]` |

**容器与槽位**（`src/item.py`）：

```
g_Items = [{}, {}, {}, {}]                # 按 type 分容器
ITEM_NORMAL=0  ITEM_TASK=1  ITEM_GOODS=2  ITEM_BAGS=3(=ITEM_STOREHOUSE)
客户端 ItemAdd/ItemPos 内部 `itype -= 1` ⇒ 线上 type 为 1-based
MAX_EQUIP_POS   = 9      → pos 0..9   装备位（容器 0 内）
ITEM_START      = 20     → pos 20..   主背包（UI 每页 30 格：20..49 / 50..79）
ITEM_FIGHT_START= 100    → pos 100..  战斗道具栏（warui「道具」菜单读此段）
```

**触发链**：无「整体背包」帧——服务端进世界时**逐件下发 `S2CItemAdd(33)`**；
客户端**悬停道具**即发 `C2SItemString(id,0)`（`item.CInterfaceItem.Enter`）等 `S2CItemString(38)` 补
`m_InfoExt`（提示附加行）；**使用**走 `C2SItemUse(34)`；**拖动**走 `C2SItemDrag(33)` → 回 `S2CItemPos(36)`。

## 3. 服务端行为

- **进世界**：逐件 `S2CItemAdd`（服务器持有 `self.items` 状态）
- **C2S 35 / 32**：回 `S2CItemString`（`m_InfoExt`，当前为空串）
- **C2S 33**：更新 `pos` → 回 `S2CItemPos`
- **C2S 34**：数量 -1 → 回 `S2CItemQuantity`；归零 → `S2CItemDel`；回血类附 `S2CPropChange(17)`
- **C2S 36/37/38**：记录忽略（本服无逻辑）
- 分发位置在**战斗指令之前**：战斗中用道具同样发这些 opcode，避免落入保底 `WarTurn`
