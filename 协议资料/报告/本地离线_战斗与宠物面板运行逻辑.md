## 2. 画面 → 逆向产物对账

### 2.1 招式详情面板 ← `data/magicdata.py`

画面字段与招式数据键一一对应：

| 画面                | 数据键                                           | 画面值（落英缤纷）                                 |
| ----------------- | --------------------------------------------- | ----------------------------------------- |
| 流派                | `type` → 流派名                                  | 剑术                                        |
| 等级                | 招式等级 `slv`（`g_Skills[ST_MAGIC][sid].m_Level`） | 1                                         |
| 类别                | 攻击/恢复/增益/减益/封印                                | 攻击                                        |
| 系别                | 单攻/群攻…                                        | 群攻                                        |
| 威力 / 速率 / 效率 / 命中 | `power` / `speed` / `rate` / `hit`            | 90 / 60 / 100% / 120                      |
| **物理抗性 4 项**      | 普通/力敌/灵巧/群攻抗性                                 | -30% / 20% / 30% / 0%                     |
| **使用消耗**          | `at` / `df` / `dp`（控制点）+ `mana` + `fp`        | 攻击点 9/0、防御点 0/0、干扰点 0/0、法力 0/100、力道 25/30 |
| 招式说明              | `desc`（含等级门槛，如「6级至其最大作用人数: 3」）                | —                                         |

> 与官网《招式属性》页一致：招式消耗 = 魔法值(法术)/力道值(武器) + 攻击点/防御点/干扰点三种控制点；
>
> 且「所有招式都拥有力敌、灵巧、群攻、普通四种物理抗性」。

### 2.2 招式可用性判定 ← `hero.GetMagicData`（hero.py:701）

```
mp   = eval(magic['mana']);  fp = eval(magic['fp'])
xinfarate = 3/4（心法 3002）else 1.0
invalid |= int(mp*xinfarate) + high['mp'] > g_Prop.m_MP      → 法力不足
invalid |= int(fp*xinfarate) + high['fp'] > g_Prop.m_FP      → 力道不足
invalid |= int(magic['at']*xinfarate) > g_Prop.m_At          → 攻击点不足
invalid |= int(magic['df']*xinfarate) > g_Prop.m_Df          → 防御点不足
invalid |= int(magic['dp']*xinfarate) > g_Prop.m_Dp          → 干扰点不足
hpNeed: 气血百分比 < hpneed → '你的气血低于%d%%，无法使用这个招式'
```

- 画面「**无法使用这个招式**」= `invalid` 为真（某一项需求超出当前值）。
- 画面「**你没有这类武器，无法释放这个武器招式**」= 武器类型校验（武器招式需装备对应武器类型）。
- 与 M4 期结论互相印证：`g_Prop.m_At/m_Df/m_Dp` 必须由 **S2CPropResist(18)/S2CPropPower(19)** 单独下发，

  否则末 8 项为 0 → any df/at/dp>0 的招式全判 invalid（即当时的「无法使用这个招式」根因）。

### 2.3 宠物面板 ← `netpet.py` + `pet.py`

面板左列（属性）来自 **S2CSummonInfo → `pet.UpdateInfo` → `CPet.UpdateProp`**，

读取 `BASE_PROP[4:]`：

```
m_Grade(1B)                                    → 等级
m_HP / m_MP / m_FP (TWORD) + HPMax/MPMax/FPMax → 气血/魔法/力道
m_Damage / m_Defense / m_Speed / m_Magdef      → 攻击/防御/速度/灵力
m_Str / m_Con / m_Mag / m_Cha / m_Dex (TWORD)  → 力量/体质/魔力/魅力/敏捷
m_Point                                        → 潜力
m_Exp / m_ExpNext / m_ExpNeed / m_Life         → 宠物经验/升级经验/寿命
```

面板右列（资质 + 抗性）来自 **S2CPropView → `CPet.UpdateAdvProp`**（`ADV_PROP`）：

| 面板字段                             | ADV_PROP 项                                    | 类型        |
| -------------------------------- | --------------------------------------------- | --------- |
| 攻击资质 / 防御资质 / 体力资质 / 法力资质 / 速度资质 | `Ability_Attack/Defense/Con/Magic/Speed`      | TWORD     |
| 更新标记 / 上限 / 进阶资质 / 进阶上限          | `Update_Flag/Update_Max/PromoteZZ/PromoteMax` | —         |
| **力敌 / 灵巧 / 群攻 / 普通抗性**          | `Resist_Lidi/Lingqiao/Qungong/Putong`         | 有符号 TBYTE |
| **仙 / 鬼 / 妖 / 智 / 念术抗性**         | `Resist_Xian/Gui/Yao/Zhi/Nian`                | 有符号 TBYTE |

- 面板中央的五角图 = 仙/鬼/妖/智/念 五术抗性；右侧方框 = 力敌/普通/灵巧/群攻 四物理抗性。
- **技能格**来自 **S2CSummonSkill**：`pid(4) + n(1) + x(1) + skill_id(2)×n`（`hfskill = n - x` 为护符技能数）。
- 攻击类型（力敌/普通）由 `petdata.GetData(shape)['attack_type']` 按造型本地取，非帧内字段。
- 携带等级 / 携带数量 1/5 由本地表与上限决定；「变异」标记来自 `m_BirthKey` 位（`pet.UseMLG` 等）。
