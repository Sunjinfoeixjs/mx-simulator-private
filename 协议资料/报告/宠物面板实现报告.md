## 1. 协议（逆向结论）

| 方向 | opcode | 常量 | 载荷 |
|---|---|---|---|
| S2C | **48** | `netpet.S2CSummonInfo` | `pid(4) name(20定长) shape(2) desc(变长) + BASE_PROP[4:]` |
| S2C | **49** | `netpet.S2CSummonSkill` | `pid(4) n(1) x(1) skill_id(2)×n`（`hfskill = n-x`） |
| S2C | **50** | `netpet.S2CSetFight` | `pid(4)` |
| S2C | **51** | `netpet.S2CPropView` | `pid(4) extra_zz(2) + ADV_PROP(18 项)` |
| C2S | **129** | `C2S_SUMM_VIEW` | `pid(4)` —— 打开面板且 `m_UpdateProp==False` 时发 |
| C2S | **131** | `C2S_SUMM_SET_FIGHT` | `pid(4)` |
| C2S | 128/130/132/133/134 | FREE/RENAME/PUT/TAKE/ADDPOINT | 本服仅记录 |

`BASE_PROP[4:]` 逐项（`CPet.UpdateProp`）：

```
m_Grade(1) m_HP(4) m_MP(4) m_FP(4) m_HPMax(4) m_MPMax(4) m_FPMax(4)
m_Damage(4) m_Defense(4) m_Speed(4) m_Magdef(4)
m_Str(2) m_Con(2) m_Mag(2) m_Cha(2) m_Dex(2) m_Point(2)
m_Exp(4) m_ExpNext(4) m_ExpNeed(4) m_Life(4) m_MoLingGuo(1)
```

`ADV_PROP` 18 项（`CPet.UpdateAdvProp`）：

```
Ability_Attack/Defense/Con/Magic/Speed (2×5)      ← 五项资质
Update_Flag(4) Update_Max(4) PromoteZZ(1) PromoteMax(2)
Resist_Lidi/Lingqiao/Qungong/Putong (有符号1×4)   ← 四物理抗性
Resist_Xian/Gui/Yao/Zhi/Nian (有符号1×5)          ← 五术抗性
```

客户端触发链（`dlgpet.py`）：面板绑定宠物 / `ShowSwitch` 时若 `m_UpdateProp==False`
→ `netpet.C2SSummonView(pid)` → 服务端回 op51（并置 `m_UpdateProp=True`，此后不再重复请求）。

## 4. 附带修复：启动器「脚本错误」模态框已消除

现象：启动器内嵌 IE 加载官方 HTML 页（MiniPage 等），页内引用已失效的
`http://image.duoyi.com/js/jquery.min.js` → 弹「脚本错误」模态框；
该模态框对 SendKeys / WM_CLOSE / BM_CLICK 均不响应（`Internet Explorer_TridentDlgFrame`，
内部只有 IE 渲染面，无 Win32 按钮），是启动流程唯一的人工干预点。

处置：
1. `tools/sim/local_http.py`：未匹配路径改为回**空白 HTML**（原先 404）；
2. 客户端 `update.ini`：`MiniPage/DownPage/GuidePage/OfficalPage/ForumPage/GameInfoPage`
   → `http://127.0.0.1:8080/blank`（备份 `update.ini.bak_before_localhtml`）。

结果：客户端**直接进入游戏**，无需人工关闭对话框（实测 `_shot_27.png`）。

## 5. 另发现：C2S 192 = `C2S_COMMON`

客户端**在战斗中也会**批量上报点击统计（`netcommon.C2SSendLog`：sub=1 + n(1) + [logid(1) cnt(2)]×n，
实测世界 1 条 / 战斗 9 条 48B）。原先落入战斗保底分支被多回一帧 WarTurn；
现已显式识别（记录条数，不应答）。
