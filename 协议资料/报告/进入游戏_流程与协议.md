## 1. 七步链路详图

### ① 启动（mx.exe → 登录主界面）
- `mx.exe`(2.1MB) / `gameplayer.exe`(722KB) 内嵌 CPython 2.6（重编号 opcode）
- 启动链：`init.py`（配 sys.stdout/stderr + sys.path）→ `main.py Start(mode)`
- `Start()`：黑名单检查 `blacklist.StartCheck()` → 音量/光标/UI 初始化 → **`mainpage.Show(True)`** 显示登录主界面 → 播放登录音乐

### ② 选服（server.ini → 服务器列表）
- `selectserver.ServerInfo()` 读 `g_ServerIni`（mx.ini [Game] serverini，默认 server.ini）
- 三层解码（上轮已破：`-1\r\n`+zlib+**模256加法cipher**）→ 6 大区 205 服
- 解析器 `CSearchServerListBox.AliasServerName`：每行 4+ 字段，`lstr[3][1:-1]` 取 `(父服)` 别名
- 点服务器 → `selectserver.Connect(fieldname, servername, ip, port, proxy)`

### ③ 连接（TCP + 裸奔 IP）
- `connect.CMXNet.__init__(proxy, ip, port)` → `net.CNet(ip, port)`，注册 `S2CHello` 回调
- `ConnectServer()`：`netobj.Connect(ip, port)`（原生 CNetClient.Connect）
- **`NakedSend(chr(ip[0])+chr(ip[1])+chr(ip[2])+chr(ip[3]) + chr(port&0xFF)+chr(port>>8&0xFF)+chr(port>>16&0xFF)+chr(port>>24&0xFF))`**
  —— 把 ip/port 各拆成 4 字节裸发（服务端校验用，未加密）

### ④ 握手（Hello → SetSeed → 加密通道建立）★核心
服务器连上先发 Hello 包，客户端 `netlogin.S2CHello(netobj)`：

```python
seed      = netobj.UnpackInt(4)          # 4字节种子
g_ServerNum = netobj.UnpackInt(2)        # 2字节服务器号
net.g_Net.SetSeed(seed)                  # ★ 之后所有报文经此种子加密
net.g_Net.m_Hello = True
seed = (seed + 0x100000000) % 3227993 + 2562088 ^ 6636321   # 混淆（C0=2^32，见 M1_协议规格.md §3）
netobj.NakedSend(chr(seed&0xFF)+chr(seed>>8&0xFF)+chr(seed>>16&0xFF) + '\x00'*22)  # 25字节回应
selectserver.Show(False); loginin.ShowLogin()               # 切换到帐号登录框
```

### ⑤ 登录（C2SLoginIn 报文全解剖）
`loginin.LoginOk()` 校验：**帐号须纯数字**（`^[0-9]+$`）、**密码恰 6 位** → `netlogin.C2SLoginIn(name, pwd)`：

```
PacketPrepare(C2S_LOGIN_ACCOUNT_ENTER)
  PacketAddI(CLIENT_SCRIPT_VERSION[0], 1)   # [0,10,43] 脚本版本
  PacketAddI(CLIENT_SCRIPT_VERSION[1], 1)
  PacketAddI(CLIENT_SCRIPT_VERSION[2], 2)
  PacketAddS(name, 32)                      # 帐号
  PacketAddS(pwd, 20)                       # 密码(明文上总线!)
  PacketAddI(n1,1)+PacketAddI(n2,1)+PacketAddI(n3,2)   # C_sys.GetVersion 客户端版本
  PacketAddI ×3                                            # update.ini [Setting] Version = 1.1.50
  PacketAddI ×4                                            # 本机IP 4字节(g_OverdoVersion时伪造192.168.x.x)
  PacketAddI(adsid>>32,4) + PacketAddI(adsid&0x37FFFFFFF,4)  # 广告ID 8字节
  PacketAddI(len(tgId),1) + PacketAddS(tgId,len)              # 推广ID
  PacketAddI(driveid,4)                                        # 硬盘序列号
  PacketAddS(mac,len(mac))                                     # MAC地址
PacketSend()   → 经 SetSeed 密码加密后入发送队列
```

### ⑥ 选角色 → ⑦ 进入世界
- `S2CLoginRoleInfo` → 角色列表（`EnterSelectRole`）→ `C2SLoginPlayerEnter(id)`
- `S2CLoginRoleEnter` → `mainpage` 游戏主界面（进游戏！）
- 无角色时 `C2SLoginPlayerAdd(name, shape, color, major)` 建角色
- 登录态维持：`g_PingTimer` 周期 Ping；`net.g_Net.m_Hello` 标记握手完成

## 2. 协议分层（Python ↔ Native）

| 层 | 位置 | 内容 |
|---|---|---|
| 脚本层 | `login/netlogin.py` 等 44 个 net*.py | C2S/S2C 语义（约 1,194 个协议函数） |
| 封包层 | mxmain.dll `CNet`（原生） | `PacketPrepare(i)` / `PacketAddI(v,size)` / `PacketAddS(s,len)` / `PacketSend()` / `NakedSend()` / `UnpackInt(n)` |
| 加密层 | mxmain.dll `0x43cc50`（状态在 CNet 对象 +0x1090） | **SetSeed(seed) 之后的报文全加密**；NakedSend 不走加密 |
| 录像层 | `g->0x28` 标志（0x681570） | `==0` 正常模式（录制开），`!=0` 回放模式——已实证（PacketSend/RecordString 同源判断） |

**待攻剩余项**：`0x43cc50` 密码算法本体（流密码，种子来自服务器 Hello）——这是复现协议最后一关。
