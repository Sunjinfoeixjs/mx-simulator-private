## 二、归档容器格式（FLS / 0SLF）

```
偏移 0x00   char[4]  魔数 "0SLF"
偏移 0x04   uint32   条目数 (485)
偏移 0x08   uint32   索引表偏移 (0x12E3C41)
...         payload 区
索引表       条目数 × 16 字节，整表加密
```

**索引条目解密算法**（取自 `mxmain.dll` sub_448CF4）：

```
key  = i * 0x0E7C83D2                    (mod 2^32)
f3'  = f3 ^ (f2 * i * 0xF718FE + 0x0D59D16C)
f2'  = (f0 * f1 + 0x0DF25E) ^ f2
f1'  = (f0 + key) ^ f1
f0'  = f0                                 (路径哈希)
```

每个条目：`f0` = 路径哈希，`f2` = 长度，`f3` = 数据偏移。


## 四、★ 关键突破：第二层混淆算法 ★

### 4.1 发现过程

1. 解出的一批 payload 前若干字节是**完全合法的 marshal**（`63 00 00 00 00` = `TYPE_CODE` + argcount + nlocals），
   但会在某个偏移突然出现非法类型码（`0x40` / `0x94` / `0xCB` …）。
2. 对最小样本（219 字节）逐字节分析，发现**密钥呈分段常数**：`0x8D`(86B) → `0x51`(99B) → `0xDD`(34B)。
3. 用该分段密钥解码后，**marshal 完整解析通过**，还原出 `filename='script\lib\md5.py'`。
4. 转向 `mxmain.dll` 的反编译代码，在 `__import__` 钩子内定位到原始算法（`decompiled_all.c` 第 15511–15553 行）。

### 4.2 算法原文（反编译）

```c
// 阶段 1：由「模块名」推导 32 位种子
uVar8 = 0;
for (i = 2; i - 1 < strlen(name); i++) {
    uVar7 = (unsigned char)name[i - 2];
    iters = (i - 2 < 5) ? (i + 5) * (i - 1) * i : (i + 5) * (i + 1);
    while (iters-- > 0)
        uVar7 = uVar7 ^ ((uVar7 * 0x7e79 + 0x29a139f) % 0x7879);
    uVar8 = uVar8 ^ uVar7;
}

// 阶段 2：按段 XOR（段内密钥恒定，段长由种子高位决定）
i = 0;
do {
    next = i + (uVar8 / 256) + len / 5;
    for (; i < next && i < len; i++)
        buf[i] ^= (unsigned char)uVar8;
    uVar8 = uVar8 ^ ((uVar8 * 0x788b + 0x24543df) % 0x7f63);
    i = next;
} while (next < len);
```

### 4.3 算法要点

| 要点 | 说明 |
|---|---|
| 种子来源 | **模块名**（非文件路径）—— 如 `script\lib\md5.py` 用 `"md5"` |
| 种子推导 | 对名字每个字符施加不同次数的 LCG 迭代后累积异或 |
| 密钥流 | 分段常数；段长 = `seed/256 + len/5` |
| 段间演进 | `seed ^= (seed * 0x788b + 0x24543df) % 0x7f63` |
| 首段密钥 | 恰为 `seed & 0xFF`，而 payload[0] 恒为 `0x63` → 提供快速校验位 |

## 七、遗留问题

### 7.1 1 个条目未解出

`#165 f0=0x571AB2B8` —— 其模块名不在任何已知字符串中，正在后台爆破短标识符名。

### 7.2 字节码操作码被重排（影响源码级反编译）

解密后的 `co_code` 使用的**不是标准 CPython 2.6 操作码**：

| 观测值 | 标准 CPython 2.6 |
|---|---|
| `0x8F` / `0xC4` / `0x98` / `0xFB` | `LOAD_CONST=100` / `RETURN_VALUE=83` |

但**指令长度规则保持**（≥ 90 的操作码带 2 字节参数），说明是**操作码表置换**。

**影响**：目前可完整还原结构（常量、变量名、函数名、行号），但**无法直接得到 Python 源码**。
**解法**：需从 `mxmain.dll` 的 `ceval.c` 分派循环中还原操作码映射表（反编译代码已在 `mxmain_re/export/decompiled_all.c` 中）。
