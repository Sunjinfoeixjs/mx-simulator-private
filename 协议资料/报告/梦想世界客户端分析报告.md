## 三、技术架构（重点发现）

### 1. 纯原生 C++ 32 位程序，非 .NET
REA 托管代码检查确认：mx.exe 与 mxmain.dll 均无 CLI 元数据（`cli-directory-absent`）。编译器为 VC7.1（mx.exe，链接器 7.10）与 VC8.0（mxmain.dll，链接器 8.0），运行时依赖 msvcr71.dll，是典型的 2000 年代末期国产网游技术栈。

### 2. 分工明确的四进程组件
| 组件 | 编译时间(UTC) | 职责判定 | 依据 |
|---|---|---|---|
| mx.exe | 2012-08-29 | **启动器+自动更新器** | 内含调试路径 `E:\game_updater\meng_xiang_shi_jie\full\deploy\mxstartup.pdb`；导入 WININET（HttpOpenRequest/HttpSendRequest 等 12 个 HTTP API）；内嵌 mx.henhaoji.com 系列官网/下载地址 |
| mxmain.dll | 2012-09-18 | **游戏引擎与逻辑核心** | 503 个 C++ 导出符号，含网络、图形、资源、脚本全套子系统（见下） |
| gameplayer.exe | 2012-08-29 | 播放器类组件 | MFC 程序（CGdiObject），写日志到 `C:\gameplayer.txt` |
| mxupd.exe | 2008-08-05 | 补丁更新器 | 走 Winsock2 直连（socket/connect/send/recv），配合 `手动更新.bat`（`mxupd.exe patch`）使用 |

### 3. 引擎子系统（由 mxmain.dll 导出符号还原）
- **Common**：`CString`、`CFile`、`CCache`、`CRes`（含 `CResWithThreadLoad`/`CResWithThreadMulLoad` 多线程资源加载）、`CVar`、`CTimer`、`Detail::CLog/CLogFile` 日志体系
- **Common::Net**：`CSocket`、`CNetBuffer`、`CAddress` —— 基于 Winsock2（WS2_32.dll）的自研网络层，另有 snmpapi/iphlpapi 用于网络环境探测
- **Graphics**：`CScreenDDraw`（**DirectDraw 2D 渲染**，导入 DDRAW.dll）、`CCanvas`、`CBitmap`、`CImages`、`CGameWnd` —— 2D 回合制 MMORPG 典型渲染方案
- **音频**：OpenAL32（3D 音效）+ Ogg Vorbis（音乐流），经 AudioLib.dll 封装

### 4. ★ 内嵌 Python 2.6 脚本引擎
mxmain.dll 内发现完整的嵌入式 Python 痕迹：`Py_Initialize`（9 处）、`PYTHONPATH`（3 处）、`marshal`（9 处）、明确的 **"Python 2.6"** 版本字符串、`zlib.Compress`、`PyHKEY` 注册表模块等。说明游戏逻辑（任务、战斗、活动等）由 **Python 2.6 脚本**驱动——与同时代网易系回合制网游（大话/梦幻）的架构一脉相承。`data\script.fls`（19 MB，485 个条目）即为打包后的游戏脚本资源。

### 5. 自研资源格式
- **`.fls` 打包格式**：魔数 `0SLF`（即 "FLS0"），头部为小端 uint32 序列（条目数 / 哈希或索引偏移 / 版本标记 0x13049）。15 个包按内容分类：char（角色，676 MB）、interface（界面，63 MB）、magic（技能特效，47 MB）、map/mapobject（39/34 MB）、item（25 MB）、script（19 MB）、sound（18 MB）等
- **`.map` 地图格式**：魔数 `0.1M`，头部为条目偏移表。81 张地图（1001.map ~ 10xx）
- **`default`**：二进制默认配置（键位/界面布局类）

### 6. 更新与服务器配置（update.ini）
- 更新服务器：`http://mxupdate.duoyi.com/`（newupdate.txt / server7.txt / version.txt 等纯 HTTP 接口）
- 补丁下载 CDN：`http://dl.henhaoji.com:82/mx/`
- 官网/论坛：mx.duoyi.com、mx.bbs.duoyi.com（二进制内还残留旧品牌域名 mx.henhaoji.com）

## 四、安全观察

- ✅ **全部主程序均有 Authenticode 数字签名**，未加壳、未混淆，属正常商业软件形态
- ⚠️ mxmain.dll 引用 `IsDebuggerPresent`、`ReadProcessMemory`、`OpenProcess` —— 存在反调试/自我保护代码（网游常规反外挂手段，2013 年版较原始）
- ⚠️ mx.exe / gameplayer.exe 使用 `SetWindowsHookExA`（全局钩子，多用于热键/输入处理）
- ⚠️ 更新通道为**明文 HTTP**（mxupdate.duoyi.com），按现代标准存在中间人篡改风险；该客户端 2013 年后已停更，服务器基本失效
