# 战斗深化实现报告（2026-10-16）

## 一、目标

在「基础回合制战斗」之上补齐三类真实客户端行为（逆向自 `netwar.py` / `nethero.py` / `warui.py` / `hero.py`）：

1. **施法消耗扣减**——招式使用后按 `magicdata` 的 `mana/fp/at/df/dp` 扣 `m_MP/m_FP/m_At/m_Df/m_Dp`，并回 `S2CPropChange(17)` 让客户端刷新资源条（此前不扣，招式可无限连发）。
2. **战斗道具**——`C2S_WAR_ITEM(165)`（id(1)+item(4)）使用战斗栏道具，扣数量并推进回合。
3. **保护/特技/召唤族/捕捉/子女**——这些指挥菜单指令本服无专属演出，但**必须按速度序推进回合**，否则客户端永久卡在「请等待」。

## 二、关键逆向结论

| 项 | 来源 | 结论 |
|---|---|---|
| 资源属性下标 | `hero.ITEM_ALL` | **m_MP=18(TWORD 2B) / m_FP=20(TWORD 2B) / m_At=72(TBYTE 1B) / m_Df=73(TBYTE 1B) / m_Dp=74(TBYTE 1B)** |
| 消耗归属 | `hero.GetMagicData` | 客户端只对招式做「可用性」判定（`magic['at']/['df']/['dp']` vs `g_Prop.m_At/m_Df/m_Dp`），**实际扣减由服务端执行** |
| 招式 1101 流水行云 | `data/magicdata.py` | mana 0 / fp 15 / at 0 / df 4 / dp 0 |
| 战斗指令 opcode | `net.py` | 160 攻击 / 161 招式 / 162 特技 / 163 防御 / 164 逃跑 / 165 道具 / 166 召唤 / **167 保护 / 173 捕捉** / 168-174 召唤兽族 / 175 队频 / 176 查看 / 177 子女 |
| 战斗道具载荷 | `netwar.C2SWarItem` | id(1) + item(4)（指向 `ITEM_FIGHT_START=100..` 战斗栏） |

## 三、实现（`tools/sim/m4_server.py`）

### 新增常量 / 状态
- `PROP_IDX_MP/FP/AT/DF/DP`、`COST_PROPS`（下标+字宽三元组）、`HERO_RES_INIT`（初值 100）、`MAGIC_COST`（招式→消耗字典）。
- `self.hero_res`：每连接一份战斗资源快照，战斗中随用随扣、开场回满。
- `build_prop_change(idx, value, width)`：通用 `S2CPropChange(17)`，按字宽打字节（1B/2B）。

### 新增方法
- `_spend_magic_cost(conn, pid)`：遍历 `COST_PROPS`，对非零消耗 `hero_res[name]-=delta` 并 `build_prop_change` 回帧。
- `_hero_war_item(conn, target, iid)`：`C2SWarItem` → `_item_consume`（复用物品模块）→ 速度序推进。
- `_hero_war_aux(conn, op)`：特技/召唤/保护/捕捉/子女 → 速度序推进（不保底 `WarTurn`）。

### 修改点
- 招式分支 `act()` 内追加 `self._spend_magic_cost(conn, pid)`。
- 战斗分发：165/167/162/166/173/168-174/177 走专属路径；175/176（队频/查看）**不消耗行动权**（不推进回合）；其余未知战斗指令走 `_fallback_turn` 保底 `WarTurn`。
- 开场 `_start_war`：把 `m_MP/m_FP/m_At/m_Df/m_Dp` 同步回满（与回血同口径）。
- 进世界 `PropInit/PropPower` 后 `_reset_hero_res()` 重置基线。

## 四、验证

### 协议级 8/8（`_test_war2.py`，3140 实例）
```
[PASS] 移动 3 次后进入战斗（WarTurn 已到） frames=8
[PASS] 招式后 m_FP(20) = 85                   ← fp 15 扣减生效
[PASS] 招式后 m_Df(73) = 96                   ← df 4 扣减生效（1 字节属性帧正确解析）
[PASS] 招式后 m_MP(18) 未变（mana=0）          ← 无消耗的字段不回帧
[PASS] 含 WarPerform(122) 且回合结束交还操作权
[PASS] C2S_WAR_PROTECT(167) → 敌方行动帧 + WarTurn  敌方出手=[1,2,3,4,5,6]
[PASS] C2S_WAR_ITEM(165) → S2CItemQuantity(35)：2007 数量 5→4
[PASS] 用道具后回合推进（WarTurn）
```

### 真机
- 复用既有真机验证：`OP_PROP_CHANGE(17)` 在物品/宠物面板已被客户端接受（HP 实时刷新），战斗深化仅新增 FP/DF 同型帧，**接受风险低**。
- 生产服已用新代码重启（PID 7720）；客户端启动后可直接进战斗实测（施法后资源条递减）。

## 五、遗留
- `MAGIC_COST` 目前仅含 1101；其余招式消耗值可从 `data/magicdata.py` 全量生成（见 `data/manifest` 外的表达式求值）。
- 战斗中「捕捉 / 召唤兽 / 子女」仅做回合推进，无专属演出（客户端会显示「指令已下发」但无动画）。
