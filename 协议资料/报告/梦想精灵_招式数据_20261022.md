# 梦想精灵·招式数据（2026-10-22）

> 起因：把客户端「静态」跑起来（本地服 + 免提权启动），打开游戏内的**梦想精灵**小页面，
> 看它到底能提供哪些资料。结论：**技能页是本地数据浏览器，招式的主修/副修、命中/速率、
> 四系抗性、效率、基础威力、每级威力递增、控制点消耗全都在里面**——正好是服务端战斗最缺的那层。
> 数据已导出：`客户端数据/skills_encyclopedia.tsv` + `skills_levels.tsv`。

## 一、怎么跑起来的（可复现）

| 步骤 | 做法 |
|---|---|
| 客户端 | `patch/mx.bin` 副本清单改 `requireAdministrator → asInvoker`（`mx_noadmin.exe`），用 GlobalAtom `mxpatch_run/shadow` 走启动器状态机，免 UAC |
| 服务端 | `python 服务端源码/sim/singleplayer.py --no-client --port 12239 --no-encrypt` |
| DLL | **必须用免加密补丁 `mxmain.dll.nocrypto_backup`（ea2f3c46…）** |
| 登录 | 账号 `abcd123`，密码任意 6 位数字（本服不校验） |
| 打开梦想精灵 | 进游戏后点右下角「系统」（或系统菜单里的「梦想知道」） |

**两个真机结论**：

1. 原版 `mxmain.dll`（b50406bc…）+ 服务端默认 `--encrypt` 会报
   **`failed to decompress data`**——客户端解不开服务端压缩帧，卡在登录。
   现有可用组合是 **nocrypto DLL + `--no-encrypt`**。
2. 顺带修了一个**老角色无法登录**的 bug：`_apply_save()` 载入存档后没有置
   `have_role`，op1 回 `AccountInfo(0)`（无角色），客户端永远停在「正在登录中…」。
   已补 `have_role=True` + `hero_name/hero_id` 持久化；回归
   `tests/_test_returning_login.py`（ALL PASS，已挂进 `_run_all.py`）。

## 二、梦想精灵里有什么

**顶栏 8 个页签**：首页 / 任务 / 技能 / 道具 / 系统 / 召唤兽 / 其他 / 梦想论坛。

**技能页 13 个分类**：生产技能、流派招式（可展开：招式属性 / 剑法 / 笔法 / 拳法 / 刀法 /
枪法 / 暗器 / 佛家 / 道家 / 儒家 / 巫术 / 阴阳 / 升级招式）。

**单条招式详情**（以「丹青妙手（中级）」为例，见截图）：

```
【类型】流派招式        主修等级：40   副修等级：50
类型：攻击   流派：笔法   系别：灵巧
命中：110    速率：80
【抗性】力敌 -20 / 灵巧 30 / 群攻 20 / 普通 0
效率：100%   基础威力：130   每级威力递增：12
【控制点消耗】攻击点 0 …
```

这些字段与客户端 `src/data/magicdata.py` 的表达式一一对应（页面就是
`dlgmagic.py:207` 的 `power = eval(data['pow'])`、`:212` 的 `powrate` 求值结果），
所以**不连服务器也能全量导出**。

## 五、对服务端意味着什么（关键）

现在 `_hero_perform()` 的伤害是：

```python
dead = self._damage_frames(conn, wid, self._hero_attack_damage())
```

**招式伤害 = 普攻伤害**——`pow` / `powrate` / `speed` / 四抗全部没参与。也就是说：

| 字段 | 现状 | 有了这份数据可以做什么 |
|---|---|---|
| 威力 `pow` | 未使用 | 招式倍率（相对普攻），让 409 招有区分度 |
| 效率 `powrate` | 未使用 | 与威力相乘/相加的第二维 |
| 速率 `speed` | 未使用（出手序只看敌方速度） | 招式先手/后手（与角色速度合成） |
| 四系抗性 | 未使用 | 招式克制（力敌/灵巧/群攻/普通） |
| 控制点/法力/力道 | 只用 1 级固定值 | 按招式等级成长扣费（公式已展开） |
| 主修/副修门槛 | 未使用 | 学招式/升级的等级校验 |

**但要说清楚**：客户端给的是**招式参数**，不是最终伤害公式。真正的
`伤害 = f(攻击, 防御, 威力, 效率, 抗性, 等级…)` 在原服服务端，已随停服消失。
所以下一步只能做「有出处的相对模型 + 录像标定」，不能声称复刻原公式。

## 六、建议下一步

1. **招式倍率（可验证）**：先做 `伤害 = 普攻伤害 × pow/100 × powrate/100` 这类**显式 SIM**
   模型，用现有 190 场录像里的技能命中样本（WarPerform → WState）校准比例；标记 `SIM`，
   `FEATURE_STATUS` 记 simulated。
2. **消耗按等级**：`skills_levels.tsv` 已有每级 fp/at/df/dp，可直接替换
   `MAGIC_COST`（当前只 slv=1），这条是**真值**、风险最低。
3. **抗性/速率**：需要更多样本（现有录像技能样本少），先只做面板展示，不进公式。
4. **梦想精灵其他页**（任务/道具/系统/召唤兽）也是本地数据，可继续挖：
   道具页可能给物品分类，系统页给玩法规则；这次只展开了技能页。
