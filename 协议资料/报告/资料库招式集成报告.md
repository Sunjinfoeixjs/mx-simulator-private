# 《梦想世界2013资料全库》招式集成报告（2026-10-16）

## 一、来源

用户投送 `梦想世界2013资料全库.docx`（801 KB，document.xml 8.9 MB，约 35 万字符）。
经抽取（`_docx_extract.py`）确认为**官方全量资料库**：招式 / 心法 / 修炼 / 装备特技特效 / 召唤兽 / 物品 / 任务 / 玩法 / 阵法 / 子女 / 结婚 / 帮派 / 矿 / 图鉴 …… 共 11 流派招式每流派 35 个。

## 二、抽取流程

1. `tools/_docx_extract.py`：docx(zip) → `word/document.xml` → 去标签纯文本 `_docx_text.txt`。
   - 关键坑：抽取后**每个表头/值单元各占一行**（非同一行 `|` 分隔），且**空终止行 `" | "` → `.strip()` 变 `"|"`** 会被误判为非空值，导致整体错位。
2. `tools/_parse_skills_docx.py`：按「 школ 标题行 → 招式名 → `（X级招式）` 档位标记 → 4 组属性块」解析。
   - 每组属性块 = 4 个表头单元 + 4 个值单元（`主修/非主修/类别/系别`、`威力/速率/命中/效率`、`力敌/灵巧/群攻/普通抗性`、`攻击点/防御点/干扰点/是否可以精修`）。
   - 锚点用**前缀**匹配两种版式：`主修`（佛家`主修等级`/枪法`主修`）、`威力`（佛家`基础威力`/枪法`威力`）、`力敌抗性`、`攻击点`。
   - 清洗值：`.strip().lstrip('|').strip()`，管道符/空行视为空。
3. 与 `src/data/magicdata.py` 按**招式名**联立 → `data/skills_joined.tsv`（school/kind/genre/pow/speed/ar/4抗性 + 游戏内 id/type）。

## 三、结果

| 项 | 值 |
|---|---|
| 抽取招式 | **385**（11 流派 × 35，均衡） |
| 与 magicdata 联立 | **382 / 385**（仅 摇影斩/魔影斩/踏雪寻梅 3 个版本差异名未命中） |
| 每流派样例 | 佛家 业报有常(2101) / 剑法 流水行云(1101) / 枪法 杯弓蛇影(1501) … |

招式块字段（以 业报有常 为例，资料库与 magicdata 逐项吻合）：
```
主修10 非主修15 群攻 鬼 | 威力80 速率50 命中- 效率100% |
力敌-10 灵巧30 群攻0 普通20 | 攻击4 防御4 干扰0 否
```
→ magicdata 1101 流水行云 `fp='15+...' df=4` 与资料库 `攻击点0 防御点4` 在 1 级**完全一致**（已知 7 个招式 at 值 9 vs 12 差异属等级口径，已记录）。

## 四、生成与接入模拟服

`tools/sim/gen_magic_cost.py` 读取 magicdata（权威客户端数据源）+ skills_joined.tsv，产出 `tools/sim/magic_cost_data.py`：

- `MAGIC_COST`：**504 条** `{id: {m_MP, m_FP, m_At, m_Df, m_Dp}}`（mana/fp/at/df/dp 表达式按 slv=1 求值），替换此前仅含 1101 的硬编码字典。
- `MAGIC_INFO`：**504 条** `{id: {name, school, kind, genre, pow, speed, ar, 4抗性, mainlv}}`，供招式面板与战斗模拟。

`m4_server.py` 改为 `from magic_cost_data import MAGIC_COST, MAGIC_INFO`（含兜底），并由此前单教 1101 改为授予分布 6 个真实低阶招式：
`TEACH_MAGIC_IDS = [1101, 2101, 1401, 1301, 2401, 2501]`（剑/佛/刀/拳/巫/阴阳），使「招式」面板有多流派真实选项。

战斗深化 `_spend_magic_cost` 现对任意已教招式按 `MAGIC_COST` 正确扣 m_MP/m_FP/m_At/m_Df/m_Dp 并回 `S2CPropChange(17)`。

## 五、验证

- 协议级 **8/8**（`_test_war2.py`，3140 实例）：1101 流水行云扣 fp15/df4；2101 业报有常扣 mp26；战斗道具/保护/捕捉均按速度序推进。
- 生成表自检：504 条 `MAGIC_COST` / `MAGIC_INFO`，1101=(0,15,0,4,0)、2101=(26,0,4,4,0) 与资料库、magicdata 三处一致。
