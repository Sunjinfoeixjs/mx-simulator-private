| 招式伤害模型 `sim-pow-eff-anchored-v1` | 威力/效率表达式是真值，**怎么组合**是本服模型 | **模拟参数**（§7.8） |
| 宠物招式效果表（415 等） | `petskill` 只给 desc，不给数值 | **模拟参数**（`PET_SKILL_EFFECTS`） |

`world_config.json` 是外置配置层（`world_config.apply_to`）：

- 位置约束：必须在**所有可被覆盖的常量定义之后**、任何运行逻辑之前；
- 语义：地图/NPC/出口/连通/战斗调参以文件为准，文件缺失或校验不过则**整体跳过**，
  服务器永远能启动；
- 命令行 `--enemies` / `--encounter-every` **始终优先于**配置；
- `--no-world-config` 是回归测试的确定性逃生舱（模块导入时即生效）。

### 10.x 配置版本校验：落后就整体跳过

`world_config.json` 有 `version` 字段（当前 `VERSION = 1`）。
配置结构会随代码演进（加字段、改语义），旧版配置缺新字段时，
`apply_to` 的 setattr 循环会**静默跳过**那些键——结果「文件在、应用了、
但一半参数没生效」，比直接跳过更难查。

所以版本不符一律**整体跳过**：

| 情况 | `probe_config` reason | 行为 |
|---|---|---|
| `version == VERSION` | `ok` | 正常应用 |
| `version < VERSION` | `version_stale` | **跳过**，横幅告警 |
| `version > VERSION` | `version_newer` | **跳过**，提示升级程序 |
| 无 `version` 字段 | `ok` | 放行（兼容早期无版本字段的档） |

横幅输出：

```
参数来源：配置版本落后，已跳过：配置 version=0，当前需要 1；已跳过（用编辑器重新生成即可）
⚠⚠ 配置版本落后，已跳过：配置 version=0，当前需要 1；已跳过（用编辑器重新生成即可）
    当前跑的是**内置默认值**，改配置文件不会生效。
    修复：用 editor_server.py 重新生成，或删掉该文件回到默认。
```

> 用 `⚠⚠` 双叹号而不是单个 `⚠`：单个的是「一般提示」（如未启用 GM 面板），
> 双叹号留给「配置没生效、你现在看到的数值不是你以为的」这类会造成误判的情况。

> 回归 `tests/_test_editor.py` 有 8 条用例覆盖：三种版本状态的 probe/apply
> 行为、横幅告警行、修复提示。负向验证确认「不校验 / 落后仍应用 / 横幅不告警」
> 三种变异都会判红。

## 19. 使用边界与合规声明

> 这一节不是免责套话。它把「这个仓库能做什么、不能做什么、哪些结论不能拿去用」
> 逐条写死，因为本项目长期贴着三条红线工作：**已停服的老游戏、他人的著作权、
> 逆向得到的数据**。越界不会报错，只会某天被人指出来。

### 19.1 法律性质：这是谁的代码

| 资产 | 权利归属 | 本仓库的处置 |
|---|---|---|
| 《梦想世界2013》客户端（`mx.exe` / `mxmain.dll` / `data/*.fls`） | **多益网络**，著作权人 | **不随仓库分发**。仅以本机已安装的原版客户端为输入；`D:\mxsj2013\client` 属于机外本地目录 |
| 客户端内嵌的 Python 脚本（485 个模块） | 同上，属客户端程序的一部分 | 还原产物（`客户端源码/src`）**仅作本机研究**，不构成再分发许可 |
| 游戏美术 / 音频 / 数据表 | 同上 | 同上。`客户端数据/` 为本地解密副本，是**研究中间产物**，不是可分发素材 |
| **模拟服代码**（`服务端源码/tests/sim`、`服务端源码/tests`） | 本项目作者 | 原创实现。协议格式属于「为互操作而必需的接口信息」，但**具体代码表达**为原创 |
| **本文档及协议规格** | 本项目作者 | 原创整理。其中引用的字段名/常量名沿用客户端命名，属互操作必需 |

**一句话**：仓库里能公开的，是**我们自己写的服务端和文档**；客户端的任何二进制、
脚本、素材，都只在你自己的机器上当输入用。

### 19.2 使用边界（做什么是允许的）

| 场景 | 判定 | 说明 |
|---|---|---|
| 单机离线自娱（本机跑模拟服 + 本机客户端） | ✅ 本项目目标 | 不产生对外服务，不影响任何在线系统 |

| 把模拟服当作通用协议 SDK 集成进别的产品 | ❌ | 没有授权，也不保证正确性 |

### 19.3 明确禁止（这些线不要踩）

1. **不得对任何仍在运营的服务器使用**。本模拟服是**替代**服务端，不是客户端外挂；
   但如果该游戏仍在运营，连的是官方服，任何 hook / 代理 / 改包都另当别论，与本项目无关。
2. **不得分发客户端本体**。包括 `mx.exe`、`mxmain.dll`、`data/*.fls` 及其解密产物、
   还原出的 `.py` 脚本、美术资源。它们不是本项目可以授权的东西。
3. **不得商业化**。不售卖、不内购、不打广告、不做付费私服。
4. **不得用于绕过付费/授权**。加密算法（`sim/mx_crypto.py`）是为**理解协议**而还原，
   不是用来破解仍在售商品的授权保护。
5. **不得把它当作「原服规则的真值」对外宣称**。见 19.5——大量数值是本项目的模拟约定。

### 19.4 技术边界（它做不到什么）

| 做不到 | 原因 |
|---|---|
| 与官方客户端**不做任何修改**地直连 | 需要 `mxmain.dll` 的 `+0x72` 一字节补丁走明文；加密虽已还原但**运行时未启用** |
| 复刻原服的完整玩法 | 上行指令 134/134 有分支，但大量分支是「显式忽略」；帮派/交易/社交等**没有对手方** |
| 保证与当年的原服数值一致 | 经验曲线、收购价、材料配方等**真值不可得**（§10） |
| 多人大规模在线 | `MultiServer` 每连接一个会话，但无跨会话交互（无真实玩家间交易/组队/聊天） |
| 反向服务于在线客户端 | 客户端已停服，无在线服务可连接，也无从校验 |

### 19.5 结论引用规范（做研究的人尤其注意）

本项目里「真值 / 半真值 / 模拟参数」是**三种不同强度的结论**（§10 有完整表）。
对外引用时：

- 标「**真值**」的（地图/掉落池/招式表/制作产物目录）：可以说「取自客户端数据」；
- 标「**半真值**」的（伤害/血量/速度/会心）：必须同时说明**样本量**与**录制来源**，
  例如「会心率 0.35 是本服约定，录像样本不足以定按造型的取值」（见 §7.4 的作废记录）；
- 标「**模拟参数**」的（经验/收购价/力量加成/材料配方）：**不得**表述为原服规则。
- **物伤公式尤其注意**：模拟服默认的 `reverse`，公式形状有反编译出处，但 `A/D/P/Lt`
  映射欠定、参数取值是模拟值——把它写成「已复刻原服物伤公式」仍是**错误结论**。
  `linear`（可选）则连公式形状都来源不可考，更没有资格谈还原度。
  §7.5.2 有完整说明。

> 历史教训：2026-10-18 曾据 137 场录像得出「野狼必红、企鹅不会心」，后被
> MSB-first 位序与语料分族两个问题推翻（有效样本仅 1/2）。**2026-10-21 语料更新为 198/190，会心重写为半真值 {2130: 0.38}，CI 含 0.35**。这类结论一旦对外发布，
> 撤回成本远高于当初多花半天核对。

### 19.6 数据与隐私

- 模拟服**不联网**：唯一的外部联系是本地 HTTP 劫持（`127.0.0.1:8080`）与回环 TCP；
  GM 面板 / 调试台都只绑回环。
- 存档是**本地明文 JSON**（`save/role_<账号>.json`），不含任何真实身份信息；
  账号即你在登录框里输入的数字串。
- 调试台导出的 `jsonl` 帧日志同样只含协议字节，不含个人信息。
- 若你把自己的存档/日志贴到公开渠道，请自行确认其中没有不希望公开的内容。
