## 二、最有价值的一条：场景遇怪

### 2.1 之前是什么样

`m4_server` 的遇怪是全局常量：

```python
ENEMY_SHAPE = 2130   # 野狼
ENEMY_NAME  = '野狼'
```

`_start_war()` 不看当前地图 —— 在永泽城站着也能刷出野狼，在天水平原也是野狼。
而掉落其实早就按场景走了（`drop_data.DROP_BY_SCENE`，43 个场景真值池），
**「掉什么」是真值、「遇什么」是常量**，这是明显的断层。

### 2.2 现在是什么样

新增 `encounter_data.py`（生成物），把三份真值联立：

```
《梦想世界2013资料全库》场景表  →  场景名 / 场景等级 / 怪物名单
客户端 monsterdata.py           →  怪物名 → shape（105 条）
world_config.json world.maps    →  场景名 → mapid（60 张）
```

结果：**43 个野外/迷宫场景、124 条怪物，全部解析成功（0 条未解析）**。
另有 17 张城镇/室内地图不在表内 → **不再遇怪**（这才是原版行为）。

运行时逻辑：

- `_encounter_def()`：当前地图的遇怪定义，城镇返回 `None`；
- `_encounter_allowed_here()`：`per_map=true` 时只有表内地图能踩雷；`false` 时恢复旧行为；
- `_start_war()`：从本图名单里选一只，用它的**真名 + 真 shape**；HP 仍取 `ENEMY_HP=100`；
- GM 战斗快照多一个 `scene` 字段，面板能看到「这一场是哪张图的怪」。

### 2.3 为什么不是「随便换皮」

怪物名 → shape 不是猜的：`monsterdata.py` 是客户端自带的 105 条图鉴表，
每个怪物有唯一 `shape`（如 青蛙怪 2081、小兔子 2040、小蜜蜂 2030）。
资料表的每个名字都能在表里找到；找不到的 3 条（`闪电侠（稀有）` 等）是**括注**，
去掉「（稀有）」后命中 2770/2780/2790 —— 生成脚本对这种情况只做**白名单式**去括注，
其余未解析项直接让脚本 `exit 1`，不允许静默跳过。

### 2.4 回归

`tests/_test_encounter_map.py`（已挂进 `sim/tests/_run_all.py`）：

| 组 | 断言 |
|---|---|
| 数据自洽 | 43 场景；mapid 全在 `MAPS`；124 条怪物都有名字+shape；城镇不在表内；天水平原名单 = 青蛙怪/小兔子/小蜜蜂 |
| 开怪 | 天水平原 `_start_war` 出的敌方名字 ∈ 本图名单，shape 与 monsterdata 一致 |
| 闸门 | 永泽城走 3 步 `in_war=False`；天水平原走 1 步 `in_war=True`；`per_map=false` 回落 `野狼` |

实测输出：`ALL PASS`。相关老测试（enemy_skills / enemy_speed / map / damage / truth_audit /
progression_config / persist / drop / craft）全部保持通过。

### 3.3 修炼经验（真值，但本版客户端没有入口）

公式（两处独立来源完全一致）：

```
攻击/法术修炼：411 + n·177.179 + n(n-1)/2·68.0559 + n(n-1)(n-2)/6·2.89
防御/抗法/四种指挥：274 + n·117.855 + n(n-1)/2·45.4319 + n(n-1)(n-2)/6·1.921
```

重算校验：0→1 = 411 / 274，29→30 = 43740 / 29156，与原文表逐位一致；上限 30（飞升 35）。

**但不入代码**：在 `客户端源码/src/dialog/`、`net.py`、`hero.py` 里搜「修炼」零命中 ——
本版客户端（2013 v1.1.50）没有修炼面板/协议。资料全库描述的是更高版本的系统。
先确认客户端是否存在隐藏入口，再决定是否实现；否则做了也没地方点。

## 四、仍然不可得（这次认真找过）

| 项 | 为什么没有 |
|---|---|
| 人物升级经验 1→140 | 官方资料库无表；端游停服；198 份录像只有战斗帧（op112–129），**op17 一次都没有** → 拿不到 `m_Exp/m_NextExp`。线上搜到的 `dream-world.fandom.com Level Chart` 是另一款同名英文 MMO（最高 150 级、经验曲线形态完全不同），已排除 |

| 每场怪物数量/权重 | 场景表只有名单，没有战斗编组 |
