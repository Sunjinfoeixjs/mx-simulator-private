## 1. 验收口径：「连续完整流程」怎么算成立

含糊的「能玩」不能作为验收结论，按下面四条判定（全部满足才算 PASS）：

| 编号 | 口径 | 判定依据 |
|---|---|---|
| C1 | **单会话**：客户端全程不重启、不断线重连 | 日志里握手成功（`② Hello PASS`）**只有 1 次**；闸门会数 |
| C2 | **连续**：同一会话内至少 **2 场**完整战斗（遇怪 → 出指令 → 敌方回合 → WarEnd → 场景恢复），中间不回登录/选角 | 闸门 `--min-battles 2` |
| C3 | **覆盖**：其中至少 1 场让**召唤兽**真的出过指令（宠物菜单能弹、能选攻击/招式/防御） | 闸门 `--min-pet 1` |
| C4 | **无残留**：每场战斗结束后回到地图，**无**常驻「请等待」、无空地图、无战斗单位残留；NPC 对话/商店/任务/传送各至少成功 1 次 | 人工勾选 §4、§5 |

> C2/C3 是「连续」的硬指标，C4 是「完整」的硬指标。C1 一旦不满足（重连过），
> 本次验收判 **FAIL**，但请把重连发生的时间点与客户端表现记进 §8，那是 bug 线索而不是废数据。

## 3. 操作脚本（一次跑完，中途不要重启客户端）

按顺序做，**每条做完记一次截图**（文件名建议 `A1_login.png` … `A9_rebattle.png`）：

1. 启动 → 启动器「已是最新版本 1.2.73」→「进入游戏」
2. 选服界面点「本地测试服」→ 登录界面
3. 登录（账号密码）→ 选角界面（有角色则直接列角色）
4. 选角/建角 → 进世界（地图 + 角色 + 宠物随行）
5. 走向野外图遇怪（或按需走到暗雷区域）→ 战斗界面
6. 主角选「普攻」→ **宠物菜单弹出** → 选「攻击」→ 观察敌方回合 → 战斗结束回地图
7. 再打一场：主角选「招式」→ 宠物选「招式」→ 观察招式演出/飘字 → 结束回地图
8. 找 NPC：对话 → 选项 →（商店买一件 / 接一个任务）
9. 找传送使切一张图 → 在新图再遇怪打一场（验证切图后 battle 仍正常）
10. 退出游戏（这一步之后才去看日志，日志会被完整刷盘）

> 第 6/7 步是本次验收的重点：**宠物菜单弹不弹、能不能连续两场都弹**，
> 是「召唤兽指令族」在真机上唯一的判据。

## 5. 战斗专项（与 §4 可同时观察，逐项打勾）

| 项 | 看什么 | 常见误判 |
|---|---|---|
| 攻击 | 攻击动画 + 受击动画 + 橙字伤害 | 若演成**闪避**、或飘**蓝字**，是 `ward`/`hp_chg` 符号错（服务端回归已守，真机若出现立刻记 bug） |
| 招式 | 招式名弹字 + 特效 + 伤害；放完**不卡「请等待」** | 卡住 = 没回 `S2CWarPerform(122)` |
| 召唤兽 | 主角选完动作后**弹宠物菜单**（攻击/招式/防御/道具/保护/逃跑），选完立即演出 | 不弹 = `S2CWarSummon(129)` 没在 `WarAdd` 之后；选完不演出 = 指令未被识别 |
| 敌方回合 | 敌方按速度依次行动；打我或打宠物都有受击 | 打主角时血条与数字要一起变（血条靠 `HPPercent`，数字靠 `WState`） |
| 死亡 | 击杀时有**死亡动作**（不是站着消失） | 站着消失 = `life` 不是 2(DEAD) |
| 战斗结束 | 敌方单位清空、显示结算、回地图 | 回地图后残留战斗单位 = 缺场景重同步 |
| 场景恢复 | 地图 NPC/角色/宠物都在，可继续操作 | 空地图 = `WarEnd` 后没补 `96/99/97` |
