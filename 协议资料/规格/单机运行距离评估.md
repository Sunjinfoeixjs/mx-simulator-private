> 问题：离「单机运行」（客户端 + 本地模拟服、不依赖官方服务器）还有多远？
> **结论：卡点收敛为「1 个协议攻坚点 + 1 个启动链固化 + 数据面还原量」。** 三条路线中，**路线 A（客户端一字节补丁）的钥匙本轮已产出**（`mxmain_nocrypto.dll`，可直接进入实测）；路线 B/C（不改客户端）难度中等可控。
> 合规：本地互操作研究；补丁件仅本地测试用，不公开分发。

### ★ 本轮新增关键认知：+0x72 开关 = 加密 + 压缩 双开关

基于 `dll/export/decompiled_all.c`（7,416 函数）逐行核对：

- `CNet` 对象构造时 `[+0x72]=0`（明文模式）；
- `SetSeed`（`FUN_00430a60`，VA 0x430A60）结尾 `mov byte [esi+0x72], 1` 一处置位，同时打开：
  - **发送加密**：`FUN_00430ae0`（flag≠0 → `0x43cc50` 变换后发送；flag=0 → 明文直发）；
  - **接收解密**：`FUN_00430b50`（flag≠0 → `0x43cc50`）；
  - **接收解压**：`FUN_00430fe0`（flag≠0 → `CLZWDecompress` 解压；flag=0 → 原样拷贝）。
- 即后握手报文 = **加密 + 压缩（仅服务器→客户端方向）**；客户端发送**不压缩**（全代码中 `Compress` 只出现在录像写盘路径 `FUN_0041a560`）。
- 压缩为 **LZ77 族**（2KB 窗口；`Decompress@0x447610` / `Compress@0x447c10` 均在反编译中可读，可移植成 Python）。
- 真正的「墙」只剩：`0x43cc50` 加密算法本体（VMProtect 虚拟化，静态不可得）。

## 二、三条路线与距离

### 路线 A：客户端一字节补丁（★本轮已产出钥匙，最短路径）
- **原理**：把 `FUN_00430a60` 结尾的 `[+0x72]=1` 改成 `=0` → 客户端全程**明文 + 不压缩**，模拟服零加密零压缩负担。
- **已产出**（三重校验通过）：
  - 工具：`tools/patch_disable_crypto.py`（可复现；校验 md5、模式唯一性、函数特征调用表）
  - 补丁件：`data/samples/mxmain_nocrypto.dll`
    - 源 md5 `b50406bc0c1b73287d35aab0cca93017` → 补丁后 sha256 `ebc1af60…c335ea`
    - 唯一差异：文件偏移 `0x2FED2`（VA 0x430AD2）`01 → 00`，共 1 字节
- **待实测风险**：① VMProtect 是否做完整性校验（未知）；② 启动器是否校验 DLL 签名（未知，必要时绕过启动器直启）。
- **距离：最近** —— 换 DLL + 固化启动 + 最小模拟服，一个工作段内即可做「本地接通」演示。

### 路线 B：不动客户端，动态还原 0x43cc50（最干净）
- 手段：真机 x64dbg / REA 在 `0x43cc50`（或 VM 入口）下断，抓 `(seed, 明文, 密文)` 三元组 → 拟合/单步；LZ77 按可读的 `Compress` 移植。
- **距离：中**（依赖动态调试环境；GUI 客户端需在你本机跑）。

### 路线 C：抓流 KPA（不碰 VM 的替代）
- 首包 C2SLoginIn 是「仅加密不压缩」，明文可完整重建 → 最小模拟服接上后直接 KPA 出密钥流；固定种子即可先打通登录。服务端回包按 LZ77 实现压缩。
- **距离：中**。

## 三、里程碑距离（定性）

| 里程碑 | 内容 | 距离 |
|---|---|---|
| M1 本地接通 | 客户端连上本地服，完成 Hello → 登录包往返 | 路线 A 下：**近**（一个工作段） |
| M2 进选角 | 还原 `S2CLoginRoleInfo` + 造角色数据 | 近-中 |
| M3 进世界 | 入口链 S2C 数据面（地图/自身/实体同步） | 中 |
| M4 可玩 | 服务端逻辑（移动/战斗/NPC/任务） | 远（量级大） |

> M2/M3 是「工作量」而非「技术墙」：484 个脚本全可读、战斗/物品拆解方法论已验证可复用。
